This is a simulator, not a real AI model. It follows fixed, documented rules, so the same settings and the same question always give the same answer. That makes it a safe place to see what each part around a model does.

How the simulator decides
  1. Scope check (Guardrails). If the off-topic rule is on and the question matches a built-in off-topic word (poem, joke, recipe, and similar) or a "Forbidden topics" line in the instructions, a fixed refusal is sent and the model is not called. If the rule is off, the simulator answers anyway.
  2. Retrieval (Context). Documents are cut into chunks of whole sentences up to the chunk size. Each chunk is scored by how many of the question's words (after dropping filler words) it contains. The top-K chunks with enough overlap go into the folder.
  3. Memory. If memory is on, every saved note goes into the folder. The simulator reads three kinds of notes: name: X, an order id like ORD-9001, and the phrase "prefers email".
  4. Tools. An order id (ORD-1234) calls the order lookup. A price, cost or stock question that names a catalog product calls the price/stock lookup. A tool that is switched off is never called.
  5. Model. It answers only from the folder, in this order: refund, missing order, order status, price or stock, document sentences, and otherwise "I don't have that information". It never makes up facts. For documents it picks the sentence that matches the most question words, then adds more sentences only if they match at least two new words.
  6. Refunds (Guardrails). The model always proposes to approve a refund. If the refund guardrail is on, code checks the window (days) and the limit ($). Past the window it refuses. Over the limit it drafts the request for a human, or refuses if human approval is off. If the guardrail is off, the proposal goes straight through.
  7. Instructions (Context). The simulator reads four things from the text: whether it contains "cite", an email address to give when unsure, an "Allowed topics:" line, and a "Forbidden topics:" line. It does not understand the rest of the prose, which a real model would.
